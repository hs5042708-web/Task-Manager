🚀 TaskFlow: A Modern Task Management Experience
TaskFlow is a sleek, professional-grade To-Do application designed for high-productivity environments. It features a robust architecture, persistent data storage, and a fully responsive interface that adapts to any device.

✨ Key Features
📱 Fully Responsive UI: Crafted with a "Mobile-First" approach using CSS Media Queries.

💾 Persistent Storage: Integrated with LocalStorage so your tasks stay safe even after a page refresh.

🎯 Intelligent Filtering: Categorize tasks into All, Completed, and Incomplete views for better focus.

⚡ Real-time Feedback: Smooth Toast notifications for every action (Add, Edit, Delete).

🎨 Dynamic Empty State: Features a delightful "All Done" screen when you've cleared your schedule.

🛠 Advanced CRUD: Inline editing and confirmation popups to prevent accidental deletions.

🛠 Tech Stack
HTML5: Semantic structure for better accessibility.

CSS3: Custom properties and Flexbox for modern layout management.

JavaScript (ES6+): Clean, modular logic for state management and DOM manipulation.

FontAwesome: High-quality vector icons for a premium feel.
